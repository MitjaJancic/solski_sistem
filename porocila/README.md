# Poročila

Struktura sledi navodilom (3. poglavje – Skupne zadolžitve in 5. poglavje –
Časovni načrt):

```
porocila/
  teden-1/
    dnevna/
      mitja.md   ← vsak dijak dopolnjuje svojo datoteko
      nal.md
    tedensko-porocilo.md
  teden-2/ ...
  teden-3/ ...
```

**Dnevno poročilo** (vsak dijak, vsak delovni dan): datum + natančen opis, kaj
je bilo tisti dan narejeno, kaj dokončano, kaj ni uspelo in zakaj.

**Tedensko poročilo** (skupno, do pol strani): povzetek napredka, sklepi
tedenskega sestanka s skupino/mentorjem, načrt za naslednji teden.

## Opomba k tednom 1–3

Ogrodje projekta (repozitorij, Docker okolje, Django aplikacija z
administratorskim CRUD-om, dokumentacija, wireframi) je bilo pripravljeno v
enem začetnem delovnem srečanju (glej dnevni zapis spodaj), kar pokriva večino
tehničnih zahtev za 1.–3. teden vnaprej. Dnevna poročila za preostale delovne
dneve posameznega tedna (pregled, popravki, sestanki z mentorjem) dijaka
dopolnjujeta sproti, ko dejansko potekajo.
